# Aurora Ecosystem

Vitrine institucional do ecossistema Aurora: inteligência artificial, produtividade, integração e automação.

## Desenvolvimento

```bash
npm install
npm run dev
npm run build
```

Next.js, React e TypeScript. A primeira versão usa CSS e SVG sem dependências gráficas adicionais. O catálogo em `app/projects.ts` é editorial, não telemetria em tempo real; os estados devem ser revisados antes de divulgação. Nenhuma credencial ou dado de repositório privado deve ser incorporado ao frontend.

## Roadmap do site

- [x] Landing page e catálogo responsivo
- [ ] Revisão de estados, documentação e screenshots por projeto
- [ ] Integração GitHub somente com metadados públicos ou explicitamente aprovados

MALO será incorporado ao Aurora AI; não é um produto independente nesta vitrine.
